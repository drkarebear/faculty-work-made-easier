OER & ZTC tools

What kind of OER help do you need?

One resource helps you browse a focused English OER shortlist. The other gives you reusable AI-assisted workflows for searching, comparing, mapping, and adapting OER and ZTC materials.

Choose a starting point

Two different jobs, two different tools.

You can use either resource independently. Choose the one that matches the task you are doing now.

English OER shortlist

CCC English OER Picks

Start with a manageable shortlist.

Browse course-centered OER possibilities for California Community College English courses. The goal is to make first-pass discovery easier while keeping faculty review and course fit central.

Best for: “Show me OER possibilities I can actually look through for an English course.”

AI-assisted workflow

The OER Promptbook

Let AI help with the searching, not the deciding.

Use reusable prompts and workflows to narrow searches, compare possibilities, map materials to a course, investigate ZTC ebook options, and organize first-pass OER work.

Best for: “Help me search, compare, organize, or plan my own OER/ZTC process.”
Open The OER Promptbook

Not sure which one to choose?

If you mainly want to browse English materials, start with CCC English OER Picks. If you mainly want help with the process of searching, comparing, or planning, start with The OER Promptbook.
